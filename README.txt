CEC Admin Portal – Functional Front-End Demo

How to run:
1. Extract this ZIP file.
2. Open the folder in VS Code.
3. Keep index.html, style.css, dashboard.js, logo.png, and dragon.png in the same folder.
4. Open index.html in your browser or run it with the Live Server extension.

Changes in this version:
- Removed the login screen; the dashboard opens directly.
- Removed logout controls because no login session is used.
- Replaced the logo with the official Cebu Eastern College seal (logo.png, transparent background).
- Added a dragon graphic (dragon.png) to the sidebar.
- Added a Log out button beside Contact (demo only: shows a logged-out screen; no real login/session).
- Keeps the interactive dashboard, navigation, student records, announcements, grade records, profile editing, search, and browser-local saving.

Note: This is a front-end demo. Data is saved in the current browser using localStorage, not in a shared database. A backend is needed for secure authentication and shared data storage.
